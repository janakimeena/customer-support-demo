BookNest MCP Host

This page is the host. It has one MCP client connected to the BookNest server over stdio.

You→Host (this app + Gemini)→MCP client⇄ JSON-RPC over stdio ⇄booknest-mcp.jar

1. What the server advertised

Found during discovery (initialize, tools/list, resources/list, prompts/list). No model involved.

Connecting…

2. Ask the model

Gemini sees the tool descriptions and decides which to call. The host runs each call and sends the result back.

3. Use the server's prompt

The host fetches recommend-books with prompts/get and sends the filled-in text as your message.
